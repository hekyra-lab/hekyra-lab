## 🛡️ Servicios

Tres líneas de trabajo — **Core**, **Security** y **Dev** — que se contratan por separado o combinadas en packs.

### 01 · Hekyra Security — Ciberseguridad 🟢

> *Auditorías, pentesting y análisis de vulnerabilidades para entender y reducir el riesgo real de tu empresa.*

**Auditoría de Ciberseguridad — dos niveles de profundidad**

| | Auditoría Básica (Nivel 01) | Auditoría Avanzada (Nivel 02) |
|---|---|---|
| Reunión inicial de contexto | ✅ | ✅ |
| Inventario de activos digitales | ✅ | ✅ |
| Revisión de sistemas, config. y accesos | General | + Políticas, backups, config. críticas |
| Detección de malas prácticas / riesgos | ✅ | ✅ Riesgos técnicos y operativos |
| Test de intrusión | ❌ | ✅ Incluido |
| Informe | Claro y priorizado | Técnico detallado + resumen ejecutivo + roadmap |
| **No incluye** | Corrección de vulnerabilidades | Corrección de vulnerabilidades |

*Tramos por nº de usuarios: 1–10 · 11–50 · 51–200 · +200.*

**Pruebas ofensivas**

- **Pentesting** — alcance definido (white/grey/black box), pruebas autorizadas, explotación ética, evidencias documentadas e informe con impacto real.
- **Análisis de Vulnerabilidades** — escaneo controlado, análisis de sistemas/servicios/apps, clasificación por severidad e informe con recomendaciones.

| Tipo de alcance | Descripción |
|-----------------|-------------|
| **White Box** | Acceso completo a información y sistemas. Máxima profundidad. |
| **Grey Box** | Conocimiento parcial, simula un atacante con cierto acceso. |
| **Black Box** | Sin información previa. Simula un atacante externo real. |

### 02 · Hekyra Security — Networking 🟢

> *Conoce de verdad cómo está construida tu red.*

**Auditoría de Red**

- **Básica:** inventario de infraestructura, revisión de topología, análisis de configuraciones, detección de errores comunes, informe con puntos críticos.
- **Avanzada:** + segmentación, VLANs y seguridad perimetral, análisis de rendimiento, diagramas lógicos y físicos, informe técnico avanzado.

*Áreas que revisamos: Switches & routers · Firewalls & perimetral · Wi-Fi & VLANs · Rendimiento & latencia.*

**Infraestructura y Hardening**

- **Hardening de Red** — endurecimiento de dispositivos, configuración segura de switches/routers/firewalls, reducción de superficie de ataque, informe técnico.
- **Instalación de Infraestructura** — diseño lógico y físico, instalación y configuración (hardening incluido), pruebas de funcionamiento, documentación completa.

> **Nota:** el Hardening va siempre incluido cuando instalamos infraestructura nueva.

### 03 · Hekyra Dev — Desarrollo 🟣

> *Software a medida, desarrollo web, automatizaciones y bases de datos diseñadas para tu negocio.*

- **Desarrollo de Software a Medida** — análisis funcional, diseño de la solución, desarrollo, pruebas y documentación.
- **Desarrollo Web Profesional** — diseño limpio, responsive, optimización, SEO/SEM básico, hosting + dominio.
- **Automatizaciones** — análisis del proceso, diseño, implementación, integración con herramientas existentes, pruebas y documentación del flujo.
- **Creación de Base de Datos** — modelo de datos, estructura (relacional o no), motor, optimización de consultas, migración y documentación técnica.

*Cómo trabajamos cada proyecto:* `01 Análisis` → `02 Diseño` → `03 Desarrollo y pruebas` → `04 Entrega y documentación`.

**Mantenimiento continuo** *(cuota mensual opcional, sin permanencia):*

- 🔄 **Actualizaciones** — librerías, plugins y dependencias siempre al día.
- 🛡️ **Hosting + Seguridad Web** — alojamiento gestionado con monitorización y protección.
- 📩 **Soporte Técnico** — resolución ágil de incidencias sin presupuestos nuevos.
